# Man & Tech Foundation

MAN & TECH — PHASE 1: FOUNDATION & BRAND

Build the first version of a premium technology company website for MAN & TECH, a digital product studio.

IMPORTANT

This is Phase 1 only.

Do NOT build the Products, Lab, CMS, Admin Dashboard, authentication, database, blog, payments or complex backend functionality yet.

The purpose of this phase is to establish the company's visual identity, website foundation, navigation and homepage.

The website must feel like a real technology company, not a freelancer portfolio and not a generic AI-generated template.

1. BRAND

Company:

MAN & TECH

Positioning:

Digital Product Studio

Core areas:

Software

Web Applications

SaaS

AI

Automation

Primary brand message:

We build digital products for the real world.

Supporting message:

Websites, applications, SaaS and AI-powered solutions designed to solve meaningful problems.

Brand personality:

Intelligent

Modern

Confident

Minimal

Innovative

Practical

Human

The company should feel ambitious but not arrogant.

2. DESIGN DIRECTION

Create a premium, minimalist software-company aesthetic.

Take inspiration from the design language of companies such as:

Linear

Vercel

Stripe

Apple

modern AI/SaaS startups

Do NOT copy any of these companies.

Instead, create an original Man & Tech identity inspired by their principles.

The design should have:

Strong typography

Large headlines

Generous whitespace

Clean grid system

Sharp visual hierarchy

Subtle borders

Sophisticated cards

Subtle gradients where appropriate

High-quality spacing

Smooth hover states

Subtle animations

Excellent mobile responsiveness

Avoid:

Generic stock photos

Cartoon illustrations

Excessive gradients

Excessive glowing effects

Overly complicated animations

Generic "AI website" aesthetics

Excessive icons

The design should look credible enough that a potential client could immediately believe Man & Tech is an established software company.

3. COLOR SYSTEM

Use a sophisticated neutral foundation.

Primary:

Near-black / deep charcoal

Secondary:

White / off-white

Supporting:

Neutral gray tones

Accent:

Choose ONE subtle modern accent color that works with the neutral palette.

Do not use many competing colors.

Create the color system using CSS variables/design tokens so the colors can easily be changed later.

4. TYPOGRAPHY

Use a modern professional sans-serif typeface.

Typography hierarchy:

Very large hero heading

Medium/large section headings

Clear body text

Small uppercase labels for categories

Strong CTA typography

Make typography one of the most important visual elements of the website.

5. NAVIGATION

Create a sticky navigation bar.

Left:

MAN & TECH

Center/right navigation:

Work
Products
Services
Lab
About

Right:

Let's build →

For Phase 1, the navigation items that are not yet implemented can link to placeholder sections or appropriate future routes.

On mobile:

Use a clean animated mobile menu.

The navigation should remain simple and elegant.

6. HERO SECTION

Create a powerful hero section.

Small label:

MAN & TECH · DIGITAL PRODUCT STUDIO

Main headline:

We build digital products for the real world.

Supporting paragraph:

Websites, applications, SaaS and AI-powered solutions designed to solve meaningful problems.

Primary button:

Explore our work →

Secondary button:

Start a project

Below this, add a subtle visual element that communicates technology and software.

Do NOT use a generic stock image.

Instead, create an abstract/product-oriented visual using UI elements, subtle grid patterns, typography, interface fragments or another sophisticated digital composition.

The hero should immediately communicate:

Man & Tech builds software.

7. INTRODUCTION SECTION

Below the hero, create a short company introduction.

Small label:

WHAT WE DO

Heading:

Technology should solve problems.

Text:

Man & Tech is a digital product studio focused on building useful software, exploring emerging technologies and turning ideas into products.

Keep this section visually simple.

8. CAPABILITIES SECTION

Create a section titled:

What we build.

Display four capabilities:

SOFTWARE

Modern websites, web applications and custom business systems.

SAAS

Subscription-based software products designed around real business problems.

AI

AI-powered applications, agents and intelligent business tools.

AUTOMATION

Digital workflows that reduce repetitive work and improve efficiency.

Each capability should have a clean visual treatment and subtle hover interaction.

9. SELECTED WORK PREVIEW

Create a homepage section titled:

Things we've built.

For now, create three elegant project placeholders.

Project 01:

AI Customer Agent

AI-powered customer communication platform.

Tags:

AI · SaaS

Project 02:

Business Intelligence

Modern analytics platform designed to help businesses understand their data.

Tags:

Web Application · Data

Project 03:

Digital Commerce

Modern e-commerce experience for growing businesses.

Tags:

Website · Web Application

Clearly structure these as replaceable project data rather than hardcoding the design into the page.

Add:

View all work →

The projects can initially use sophisticated abstract product mockups rather than fake screenshots.

10. PHILOSOPHY SECTION

Create a visually distinctive section.

Small label:

OUR PHILOSOPHY

Display these words prominently:

BUILD.

LEARN.

ITERATE.

SHIP.

Add a short supporting paragraph:

We believe the best way to understand technology is to build with it. Every project is an opportunity to learn, experiment and create something useful.

Use subtle animation as the user scrolls through this section.

11. CALL TO ACTION

End the homepage with a strong CTA.

Heading:

Have an idea?

Supporting text:

Let's turn it into something real.

Primary button:

Start a project →

Secondary:

Explore our work →

Display:

13. RESPONSIVENESS

The website must be excellent on:

Desktop

Laptop

Tablet

Mobile

Pay particular attention to:

Hero typography

Navigation

Card layouts

Section spacing

Buttons

Footer

Touch targets

Do not simply shrink the desktop design for mobile.

Create intentional responsive layouts.

14. ANIMATION

Use subtle, premium animation.

Examples:

Fade/slide-in sections

Text reveal

Card hover effects

Button micro-interactions

Smooth page transitions

Subtle hero movement

Animations must be fast and purposeful.

Avoid excessive animation.

15. CODE QUALITY

Use:

React

TypeScript

Tailwind CSS

Reusable components

Clean component structure

Semantic HTML

Accessible controls

Responsive design

SEO-friendly metadata

Separate reusable components such as:

Navbar

Hero

SectionHeading

CapabilityCard

ProjectCard

CTA

Footer

Do not create unnecessary backend functionality yet.

The code should be structured so we can expand the project significantly in later phases.

16. FINAL QUALITY STANDARD

Before considering Phase 1 complete, check:

Does this look like a real software company?

Does the Man & Tech brand feel distinctive?

Does the homepage immediately communicate what the company does?

Does it look excellent on mobile?

Are typography and spacing polished?

Are animations subtle?

Does it avoid the appearance of an AI-generated template?

Can the website easily be expanded in later phases?

Most importantly:

The website should make someone think:

"These people build software."

Do not add unnecessary features simply to make the website appear larger.

Focus on making the foundation exceptionally polished.
